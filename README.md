## 📚 Description
An ecommerce furniture website designed using HTML, CSS, and JS, providing a platform for users to browse and purchase furniture online. This project aims to demonstrate a basic ecommerce website structure and functionality.

## 🎯 Features
* User-friendly interface for browsing furniture products
* Product details page with images and descriptions
* Contact page for customer inquiries
* Simple and responsive design

## 📊 Tech Stack
* HTML: Used for structuring and creating the website's content
* CSS: Used for styling and layout (not included in this repository, but used in the project)
* JS: Used for adding interactivity to the website (not included in this repository, but used in the project)

## 🗂️ Project Structure
* `about.html`: Page containing information about the website and its purpose
* `assets/`: Folder containing additional assets (not included in this repository)
* `contact.html`: Page containing contact information and a form for customer inquiries
* `images/`: Folder containing images used on the website
* `index.html`: The main entry point of the website, containing links to other pages

## 📦 Installation
To run this project locally, follow these steps:
1. Clone the repository using `git clone https://github.com/kiranShamsHere/Ecommerce-furnitureWebsite.git`
2. Open the `index.html` file in a web browser to view the website

## 📱 Usage
To use this website, simply open the `index.html` file in a web browser and navigate through the pages using the links provided.
